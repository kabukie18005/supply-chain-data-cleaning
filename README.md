# supply-chain-data-cleaning
An end-to-end data analytics project analyzing supply chain operations using SQL, Python, and Power BI. The project explores sales performance, customer behavior, shipping performance, product categories, and operational trends to generate actionable business insights.

Dataset: DataCo Smart Supply Chain for Big Data Analysis (Kaggle) — 180,519 rows, 53 columns. Raw and cleaned CSV files are not included in this repo due to file size; see the notebook for the full cleaning process and outputs.

Contents:

- Supply Chain Data Cleaning.ipynb — data cleaning and preparation in Python/pandas
- sql_queries.sql — SQL queries run against the cleaned data for business insights
- Screenshots — Power BI dashboard pages (Data Quality, Insights, Trends & Status)
